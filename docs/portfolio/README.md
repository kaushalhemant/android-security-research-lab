# Android Security Research Portfolio

I build Python tooling to help organize Android security scanner output
into structured reports for review by experienced security assessors.

## Demonstration

See [DIVA lab report](demo/diva-lab-report.md) and the
[demo notes](demo/README.md).

The demonstration uses an intentionally vulnerable training app.
Scanner findings are not independently validated vulnerabilities.

## Service

See [Android Security Assessment Support](SERVICE_OFFER.md) for the
bounded report-processing and quality-review service I am developing.

## Current capabilities

- MobSF-style JSON report parsing
- Finding normalization and severity summaries
- Draft remediation guidance
- Markdown and JSON report generation
- Automated regression tests

## Limitations

This is a research prototype, not a replacement for manual mobile
application penetration testing. Findings, severity, evidence and
remediation require human review.
